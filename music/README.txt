JARVIS V7 - MUSICA LOCAL

Pon tus archivos .mp3, .wav, .flac, .ogg, .m4a, .aac o .wma aquí.

Ejemplo:
music\Mil Vidas.mp3

También se busca en:
%USERPROFILE%\Music

Comandos:
- "Jarvis, reproduce Mil Vidas"
- "Jarvis, pon Mil Vidas"

La reproducción local NO necesita Google, Spotify ni Internet.
Windows abrirá el archivo con el reproductor predeterminado.
